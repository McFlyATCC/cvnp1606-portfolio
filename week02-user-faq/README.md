## How do I change text size in Windows 11?

### User goal
Make text easier to read after a Windows 11 refresh without changing unrelated system settings.

### Tool path tested
Settings > Accessibility > Text size

### Steps
1. Open **Settings**.
2. Select **Accessibility**.
3. Select **Text size**.
4. Move the slider to **150%**.
5. Select **Apply**.
6. Verify that text is easier to read across Windows applications.

### Verified result
The user confirmed that **150% Text Size** restored readability and resolved the issue following the Windows 11 refresh.

### When to escalate
If display problems continue after Accessibility Text Size and Display Scale settings have been reviewed, collect the following information and escalate for further investigation:

- Device model
- Monitor model
- Screen resolution
- Current display scaling percentage
- Graphics adapter information

Escalate to desktop engineering support for display driver, monitor, or hardware review.
