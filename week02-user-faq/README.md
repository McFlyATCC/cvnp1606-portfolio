## Issue Summary

### Reported Problem

Users reported that text appeared significantly smaller following a Windows 11 refresh.

### Symptoms

- Text difficult to read
- User interface appears smaller than expected
- Increased support requests related to display readability

### Root Cause

The Windows 11 refresh process reset Accessibility Text Size settings to default values, causing text to display smaller than the user's preferred configuration.

---

## Verified Resolution

### Configure Text Size

1. Open **Settings**
2. Select **Accessibility**
3. Select **Text size**
4. Move the slider to **150%**
5. Select **Apply**

### Verified Outcome

The user confirmed that a Text Size setting of **150%** restored readability and resolved the issue.

## User FAQ

### Why is the text smaller after my Windows 11 refresh?

Accessibility settings may revert to default values during a system refresh, causing text to appear smaller than before.

### How do I make the text larger?

Navigate to:

Settings → Accessibility → Text Size

Adjust the slider to **150%** and select **Apply**.

### Will this change affect my applications?

The Text Size setting increases text throughout Windows while maintaining the overall layout of applications and desktop elements.

### Can I change it again later?

Yes. Users can return to the Text Size menu at any time and adjust the setting to meet their personal preference.
